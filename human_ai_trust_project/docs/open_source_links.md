# 相关开源代码与资源链接整理

## 1. InterpretML
- GitHub: https://github.com/interpretml/interpret
- 用途：EBM 模型训练、全局解释、局部解释、解释仪表板
- 本项目已使用资源：
  - EBM 全局解释图
  - EBM 局部解释图
  - Dashboard 仪表板图
  - 官方示例 notebook 思路

## 2. GAM Changer
- GitHub: https://github.com/interpretml/gam-changer
- 用途：GAM/EBM 的交互式编辑与人机协同修正
- 与主题关联：适合扩展“专家反馈反哺模型”的信任闭环

## 3. DimVis
- GitHub: https://github.com/parisa-salmanian/DimVis
- 用途：高维数据投影解释与 EBM 可视化分析
- 与主题关联：适合后续扩展为更复杂的科研数据解释界面

## 4. LIME
- GitHub: https://github.com/marcotcr/lime
- 用途：局部解释黑盒模型
- 与主题关联：适合和 EBM 做局部解释对比

## 5. Adult Income 数据集公开来源
- UCI 数据地址: https://archive.ics.uci.edu/ml/machine-learning-databases/adult/adult.data
- OpenML 任务入口: https://www.openml.org/search?type=data&sort=runs&id=1590&status=active
- 本项目已下载并转换为本地 CSV，用于替换原先的模拟数据。
